# カフェるん用ユーザースクリプト

コンカフェ情報サイト「[カフェるん](https://shop.caferun.jp/)」を見やすくするための、iPhone（Safari）向けユーザースクリプトです。

## 準備（最初に1回）

1. App Storeで、次のどちらかのアプリを入れます。
   - **Tampermonkey**（有料）
   - **Userscripts**（無料）
2. iPhoneの設定 → アプリ → Safari → 拡張機能 で、入れたアプリをオンにして、Webサイトへのアクセスを「許可」にします。

## インストール

下のリンクをSafariで開くと、インストール画面が出ます。

| スクリプト | できること | インストール |
|---|---|---|
| 出勤まとめ | 隣人部。とみくすろいどの出勤を1画面で表示（日別・1週間）／★推しの出勤日とGoogleカレンダー追加／来店日を選ぶと誰に何回会えるか／沖縄のカワいいね！ランキング（ボタンを押すと集計） | [インストール](https://raw.githubusercontent.com/Dai-Sunakawa/userscripts/main/caferun-shukkin.user.js) |
| カワいいね！増え方メモ | キャストページを開くたびにカワいいね！の数を記録して、前回からの増加と1日あたりのペースを表示 | [インストール](https://raw.githubusercontent.com/Dai-Sunakawa/userscripts/main/kawaii-memo.user.js) |
| キャストの今週の出勤 | キャストページに、その子の今日から7日分の出勤日（わかれば時間も）を表示 | [インストール](https://raw.githubusercontent.com/Dai-Sunakawa/userscripts/main/cast-week.user.js) |
| タブ複製（Tampermonkey推奨） | 開いているカフェるんのページを、決めたタブ数になるまで10タブずつ1分おきに複製して開く（タブを開くだけで、ページ内のボタンは押しません） | [インストール](https://raw.githubusercontent.com/Dai-Sunakawa/userscripts/main/caferun-tab-fukusei.user.js) |
| 沖縄キャストランキング | キープ中キャスト一覧の名前の横に、週間キャストランキング（沖縄・那覇）の順位と前回からの変化を表示 | [インストール](https://raw.githubusercontent.com/Dai-Sunakawa/userscripts/main/caferun-okinawa-rank.user.js) |

- **Tampermonkey**：リンクを開くとインストール画面が出るので「インストール」を押します。画面が出ないときは、Tampermonkeyのダッシュボード →「ユーティリティ」→「URLからインポート」にリンクのURLを貼ります。
- **Userscripts**：リンクを開いたあと、アドレスバーの拡張機能メニューからUserscriptsを開くと、インストールの案内が出ます。

## 使い方

- **出勤まとめ**：カフェるんのページを開くと、右下に「出勤まとめ」の丸いボタンが出ます。`https://shop.caferun.jp/#shukkin` をブックマークしておくと、開いた瞬間に表示されます。
- **カワいいね！増え方メモ**：キャストのページを開くと、左下に「♡数 / 前回から+いくつ」が出ます。タップすると推移やほかのキャストの記録が見られます。
- **キャストの今週の出勤**：キャストのページを開くと、名前の下に7日分の出勤予定（● 出勤／－ 休み／？ 未定）が出ます。日付をタップすると、その日の出勤一覧に移動します。
- **タブ複製**：カフェるんのページを開くと、左下に「⧉ タブ複製」が出ます。押すとパネルが開くので、「複製するページ」（最初は今のページ）と「目標タブ数（新しく開く数、1〜300）」を入れて「開始」を押します。1回目はすぐに10タブ、そのあとは1分おきに10タブずつ裏で開き、目標の数で止まります。進み具合は左下のボタン（例：⧉ 12/50）とパネルに出ます。止めたいときは「停止」か、Tampermonkeyのメニューの「複製を停止」を選びます。画面がロックされたり、ほかのタブに移ったりすると一時停止し、このタブに戻ると続きから開きます（再読み込みしても続きからです）。
- **沖縄キャストランキング**：キープ中キャスト一覧（`https://shop.caferun.jp/member/keep/cast/`）を開くと、名前の横に「沖縄 ◯位」のバッジが出ます。1〜3位は金・銀・銅の色になり、前回からの変化（▲上がった／▼下がった／NEW）も並びます。沖縄の店のキャストで50位に入っていない子は「沖縄 圏外」と出ます。ランキングは3時間ごとに自動で取り直します。

## 更新

新しい版は自動で届きます（アプリが定期的に確認します）。すぐ更新したいときは、Tampermonkeyのダッシュボードで「更新を確認」を押してください。

- 「カワいいね！連続実行」は「タブ複製」に置き換わりました（カワいいね!を押す機能はなくなりました）。以前のものを入れている場合は自動では切り替わらないので、Tampermonkeyで「カワいいね！連続実行」を削除してから、上の表の「タブ複製」を入れてください。

## 注意

- カフェるんの公式ツールではありません。カフェるんのページの作りが変わると、動かなくなることがあります。
- ★推しの登録、カワいいね！の記録、沖縄キャストランキングの過去の順位は、それぞれのiPhoneのSafariの中だけに保存されます。ほかの人に見えたり、どこかに送られたりはしません。
- 出勤まとめの対象店（隣人部。・みくすろいど）は今は固定です。
